## Цель (с 2026-10-23)
Фокус только на вузах. Доход — от учебных центров за приведённых клиентов.

Путь клиента:
1. Один адаптивный тест (без выбора «Университет / Работа / Подготовка»): после каждого ответа следующий вопрос зависит от него. Дерево вопросов готовое, без живого ИИ на сайте.
2. Клиент сам выбирает страны → по направлению из теста топ-3 вуза в каждой стране.
3. Кнопка «С чего начать» → один общий шаблон реальных требований для всех рекомендованных вузов.
4. Под требованиями — курсы учебных центров (пока примеры-заглушки).
5. Запись на курс — на нашем сайте: имя, телефон, город (курс, центр и результат теста — автоматически). Заявки хранятся у нас, позже передаются центру.

Остаются: калькуляторы шансов и стоимости, «Вузы мира», «Избранные вузы».
Скрыты (код не удалять): тесты «Работа» и «Подготовка», план по неделям, календарь, профессии, бесплатные ресурсы.

## Субагенты (в проекте, `.claude/agents/` — приезжают вместе с репозиторием)
| Агент | Зона |
|---|---|
| `noventis-psychologist` | дерево вопросов адаптивного теста, веса направлений |
| `noventis-frontend` | `public/` — страницы, тест, результат, «С чего начать», форма записи, меню |
| `noventis-backend` | `server.js`, API, заявки на курсы, таблицы и миграции, тесты API |
| `noventis-data` | вузы, требования, общий шаблон требований, центры и курсы, проект схемы таблиц (что хранить; код таблиц пишет backend); цифры — с официальных сайтов, с `src`/`year` или пометкой «уточнить» |
| `noventis-reviewer` | только проверка и отчёт, ничего не правит |
| `noventis-observer` | смотритель: галлюцинации (выдуманные данные, цифры, файлы) и нагрузка (вес страниц, запросы к БД, лимиты); ничего не правит |

Порядок: data и psychologist → backend → frontend → reviewer + observer (параллельно). Находки ревьюера и смотрителя чинит агент той зоны.

## Общие правила
- Код только через Write/Edit (Bash портит обратные слэши, `$` ломает `String.replace`).
- Надписи на RU/EN/UZ; `node scripts/check-uz.js` — без перевода 0; `npm test` — проходит.
- Секреты только в `.env`; ничего платного; регистрации в сервисах делает пользователь сам.
- Git: агенты не коммитят. Коммитит главная сессия после «чисто» от ревьюера, одна задача — один коммит.
